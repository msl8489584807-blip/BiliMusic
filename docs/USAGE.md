# 使用 BiliMusic

## 搜索与在线播放

首页点击“搜索音乐”，或使用底部“搜索”页，默认进入“B站音乐”。输入歌名、歌手或关键词，结果来自音乐分区；点击直接播放音轨，当前页内容组成队列，底部可翻页。

底部迷你播放器可暂停，并可点击进入完整播放器。完整播放器支持切歌、拖动进度、随机、单曲/列表循环和队列管理。后台及媒体通知由 Media3 服务管理。重开应用恢复队列与进度，默认不自动播放。

点击结果右侧爱心可加入本地收藏。音乐库中的在线曲目也可加入自己的本地歌单。

## 登录与 B站收藏夹

搜索页右上角账号图标，或设置 → 哔哩哔哩账号，进入登录页。生成二维码，用 B站扫码并确认；同一手机可截屏后从 B站相册识别。过期后刷新二维码。

已实现登录后的账号信息和本人收藏夹读取，选择收藏夹后可直接点选内容播放。这部分的真实登录与私有收藏夹需要本人在设备上验证；目前已验证二维码生成、显示、未确认轮询和离开页面取消。

会话使用 Android Keystore 加密，仅存本机，不加入音乐库备份。退出登录会清除本机会话、音轨缓存和当前在线队列项。

## 本地音乐

首页或音乐库点击“导入音乐”，使用 Android 系统文件选择器多选音频。应用读取标题、艺术家、专辑、时长与内嵌封面，缺失时使用文件名。按 URI 去重，不移动或删除原文件；实际格式支持取决于设备解码器，云端文件可能需要联网。

文件失效时保留记录，通过曲目“更多 → 重新关联音频文件”修复。

## 歌单、标签与 BV

- 音乐库 → 歌单 → 新建歌单。可重命名、收藏、添加/移除曲目；长按拖动手柄排序。删除歌单保留音乐和原文件。
- 曲目“更多 → 编辑标签”支持逗号分隔的标签。搜索页切换“本地音乐”，可搜索曲名、艺术家、专辑、标签、BV 元数据和歌单。
- 首页“通过 BV 添加音乐”，支持 BV 或可信 `bilibili.com/video/BV…?p=N` 链接。保存后点击在本应用播放；“更多 → 在 Bilibili 打开”才会外跳。格式正确不表示视频存在或账号可播放。

## 歌词、主题与定时

本地歌曲“更多 → 关联 / 更换 LRC 歌词”，选择 UTF-8 `.lrc`。支持多时间戳、毫秒和 offset；完整播放器切换歌词后同步高亮，点击歌词可跳转。

设置支持深色、浅色、跟随系统，以及 Android 12+ 动态配色。默认随机和循环影响下一次从列表开始播放。

睡眠定时器由服务到时暂停，Activity 退后台仍有效；可取消。服务或进程被系统终止后不保证保留未到期的计时任务。

## 备份与恢复

设置 → 备份音乐库，可选是否包含历史，使用系统文件选择器保存 JSON。备份包含曲目元数据、收藏、歌单顺序、标签和设置，不包含音频/封面文件、原文件授权、账号会话或临时流地址。

恢复支持合并或替换。替换会清除当前音乐库元数据，不删除音频源文件。换设备不能自动恢复 SAF 文件授权，失效记录需要重新关联。

上限：64 MB；曲目/歌单/标签各 20000，歌单及标签关联各 500000。Room 与设置存储使用异常/取消补偿，进程被强杀时不保证跨存储严格原子提交。
