# 应用图标

kirino_source.png 是用户提供的 480×481 原图；正式图标通过 scripts/generate-icons.ps1 从原图确定性裁切和缩放，没有重画脸部或声称无损提升细节。前景为 432px 独立透明层，背景为暖米金色，中央面部位于自适应安全区域。传统图标为 48/72/96/144/192px；API 33 提供角色轮廓的单色向量层。

kirino_cutout.png 是通过内置 imagegen 产生的备选透明图，仅保留供后续对照，正式图标优先使用原始素材。生成提示词：移除房间背景，保留原角色橙金头发、蓝眼、眨眼、发卡与表情，头肩构图，透明背景，不加文字、水印、其他角色或商标。
