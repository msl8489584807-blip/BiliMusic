# BiliMusic v0.2.0 — 应用内搜歌与在线播放

支持在 BiliMusic 内搜索 B站音乐，点击真实结果直接播放音轨。提供原生播放器和后台播放，同时保留本地音乐库。

## 本版功能

- B站音乐分区搜索、分页和应用内在线播放。
- 后台续播、上一首/下一首、进度跳转、随机/循环和队列。
- 本人二维码登录入口、过期刷新和本机退出，已实现登录后读取本人收藏夹。
- 已保存 BV / 分 P 默认在本应用播放。
- 保留本地音频导入、歌单/收藏/历史/标签、LRC 歌词、主题、睡眠定时和 JSON 备份。
- 账号会话在本机加密保存，不加入备份；临时音轨地址不入库。

## 安装

下载本 Release 的 `BiliMusic-0.2.0-debug.apk`，要求 Android 8.0 / API 26 以上。此包为 Debug 签名，其他构建者使用不同签名时不能直接覆盖安装。

## 验证与已知限制

已通过 12 项单元测试，以及完整 20 项集成测试和后续 5 项在线复测，共覆盖 21 个不同集成用例。Android 15 模拟器已验证真实搜索、原生音轨播放、后台进度、下一首、seek 和二维码界面；Lint 0 错误、20 警告。

本人扫码确认后的账号/私有收藏夹、One UI 锁屏、真实蓝牙/耳机及长时间播放仍待实机验证。在线能力依赖平台接口、网络和账号访问权限。暂不支持音频下载/离线缓存、MediaStore 扫描、目录导入或 b23.tv 展开。
